# Referencias consolidadas del proyecto (formato APA 7)

> Todas las referencias listadas corresponden a publicaciones reales y
> comprobables; se incluye DOI o URL de verificación para cada una.
>
> **Nota sobre la denominación del caso de estudio:** *SVIF* (Sistema de
> Videovigilancia con Identificación Facial) es el nombre asignado en este
> trabajo al sistema ciberfísico diseñado para las actividades del curso; no
> proviene de la literatura y no debe citarse como fuente. Cumple el mismo rol
> que el «invernadero automatizado» del ejemplo de cátedra.
